Regla Aplicada: id_cliente = 'ANONIMO'

Regla Aplicada: shipping_address = 'SIN_DIRECCION'

Justificación Matemática: Mediana vs. Media Aritmética

En datos comerciales omnicanal, compras masivas de bots (99 y 500 unidades) sesgan fuertemente la distribución hacia la derecha.

Distorsión de la Media Aritmética (Sensible a Outliers)
$$\bar{x} = \frac{1}{n}\sum_{i=1}^n x_i = \$16,586.74\text{ MXN}$$
La media se desplaza artificialmente hacia valores astronómicos que no representan la compra típica.
Robustez de la Mediana (No Paramétrica)
$$\text{Mediana } (Me) = \$3,506.37\text{ MXN}$$
Estimador no paramétrico insensible a valores extremos que refleja exactamente el punto central del 50% de las ventas.
Recálculo Determinista de Montos Nulos (Sin Sesgo)
$$\text{monto\_total\_mxn} = \text{cantidad} \times \text{precio\_unitario}$$
Reparó exactamente los 32 nulos de tienda física con precisión matemática absoluta ($0.0$ error de estimación).

Detección de Outliers (IQR) y Política de Capping / Winsorizing

Método Tukey: Rango Intercuartílico (Factor $\alpha = 1.5$)
$$\text{IQR} = Q_3 - Q_1 = 3.0 - 1.0 = 2.0\text{ unidades}$$
$$\text{Límite Superior} = \lfloor Q_3 + 1.5 \times \text{IQR} \rfloor = \lfloor 3.0 + 3.0 \rfloor = 6.0\text{ unidades}$$
Cualquier pedido mayor a 6 unidades es catalogado estadísticamente como transacción atípica (compra de bot / mayorista).
Capping / Winsorizing (Recorte a Umbral) 13 Registros Tratados

Principio No Destructivo: 13 transacciones de compras gigantes (99 y 500 unidades) no se eliminan. Se recortan al umbral máximo de 6 unidades, archivando la cantidad cruda en cantidad_original para fines de auditoría.

Eliminación Estricta a Cuarentena ($\le 0$) 11 Registros Rechazados

Solamente se descartan valores físicamente imposibles ($\text{cantidad} \le 0$). Se desvían a cuarentena bajo la regla VALOR_IMPOSIBLE_CANTIDAD_NO_POSITIVA.

from pydantic import BaseModel, Field, field_validator
from typing import Optional, Literal

class TransaccionLimpiaSchema(BaseModel):
    id_transaccion: str = Field(...)
    fecha: str = Field(..., description="Formato ISO YYYY-MM-DD")
    canal: Literal['FISICO', 'ONLINE']
    cantidad: int = Field(..., gt=0)
    monto_total_mxn: float = Field(..., gt=0.0)
    monto_escalado_minmax: float
    cliente_email: Optional[str] = None

    @field_validator('cliente_email')
    def validar_email_si_online(cls, v, info):
        if info.data.get('canal') == 'ONLINE':
            if not v or not EMAIL_REGEX.match(v.strip()):
                raise ValueError("Correo inválido en canal web")
        return v
